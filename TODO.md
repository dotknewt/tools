# New tools:
## Autogeneration of OS preseed/autoinstall/autounattend
- Autounattend.xml generator:
  - For Windows
  - Clone and improve this https://github.com/rbardtke/windows-unattend-generator
- Preseed.cfg generator:
  - For Debian
  - Debian Trixie preseed example: https://www.debian.org/releases/trixie/example-preseed.txt
  - Documentation: https://www.debian.org/releases/stable/amd64/apb.en.html
- Autoinstall.yaml generator:
  - For ubuntu
  - Schema: schema/ubuntu-autoinstall.json
  - Autoinstall.yaml validator: https://canonical-subiquity.readthedocs-hosted.com/en/latest/howto/autoinstall-validation.html
